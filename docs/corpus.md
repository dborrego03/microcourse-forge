## What the license means here
- **NC (non-commercial):** fine for this project, which is a non-commercial portfolio piece.
- **SA (share-alike):** lessons, quizzes and any other text generated from the book are adaptations, so they are shared under CC BY-NC-SA 4.0 too. This applies to the content, not to the code (MIT).
- **BY (attribution):** every generated lesson shows "Access for free at openstax.org" and links to the book page.
- The OpenStax name and logo are trademarks and are not covered by the license, so the UI does not use them.

Correction (2026-10-15): an earlier version of this file said CC BY 4.0. The copyright page of the PDF says CC BY-NC-SA 4.0, which is what applies.

## How to get it
The book is not committed to this repo.
1. Open the page above and download the PDF.
2. Save it as `data/raw/psychology-2e.pdf` (git-ignored).
3. Only chapters 6, 7 and 8 are ingested.
